# 📚 Library Management System

## 📖 Project Overview
The **Library Management System** is a software application designed to automate library operations such as managing books, students, and issuing records.  
This project replaces manual record keeping with a digital system for better efficiency and organization.

Developed as part of **BS Software Engineering coursework**, this project demonstrates Object-Oriented Programming concepts and software development practices.

---

## 🎯 Objectives
- Digitize library operations
- Manage book records efficiently
- Track issued and returned books
- Reduce manual errors

---

## ✨ Features
- 📘 Add new books
- 🔍 Search books
- 👤 Manage students/members
- 📤 Issue books
- 📥 Return books
- 📊 Maintain transaction records
- 🗂 Organized data management

---

## 🛠 Technologies Used
- **Programming Language:** Java
- **Build Tool:** Gradle
- **Concepts Used:**
  - Object-Oriented Programming (OOP)
  - Modular Programming
  - File/Data Handling
